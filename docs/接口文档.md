# API接口文档

## 基础信息

- **Base URL**: `http://8.138.190.51/api`
- **本地开发**: `http://localhost:8080/api`
- **数据格式**: JSON
- **编码**: UTF-8

---

## 通用说明

### 请求头

| 请求头 | 说明 | 是否必须 |
|--------|------|----------|
| Content-Type | application/json | POST/PUT请求必须 |
| Authorization | Bearer {token} | 需要认证的接口必须 |

### 响应格式

所有接口统一返回格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { ... }
}
```

### 状态码说明

| code | 说明 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或Token过期 |
| 500 | 服务器内部错误 |

## 一、认证接口

### 1.1 用户注册

**接口地址**: `POST /auth/register`

**是否需要认证**: 否

**请求参数**:

```json
{
  "username": "test",
  "password": "123456"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | String | 是 | 用户名，4-20字符 |
| password | String | 是 | 密码，6-20字符 |

**响应示例**:

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "id": 1,
    "username": "test",
    "email": null
  }
}
```

## 四、接口调用示例

### JavaScript (Axios)

```javascript
import axios from 'axios'

// 创建请求实例
const request = axios.create({
  baseURL: 'http://8.138.190.51/api',
  timeout: 30000
})

// 请求拦截器 - 添加Token
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 注册
async function register(username, password) {
  const res = await request.post('/auth/register', { username, password })
  return res.data
}

// 登录
async function login(username, password) {
  const res = await request.post('/auth/login', { username, password })
  if (res.data.code === 200) {
    localStorage.setItem('token', res.data.data.token)
  }
  return res.data
}

// 上传简历
async function uploadResume(file, targetRole) {
  const formData = new FormData()
  formData.append('file', file)
  formData.append('targetRole', targetRole)
  
  const res = await request.post('/resume/upload', formData, {
    headers: { 'Content-Type': 'multipart/form-data' }
  })
  return res.data
}

// 一键优化
async function optimizeResume(id, targetRole) {
  const res = await request.post(`/resume/optimize/${id}`, { targetRole })
  return res.data
}
```

### cURL

```bash
# 注册
curl -X POST http://8.138.190.51/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"123456"}'

# 登录
curl -X POST http://8.138.190.51/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"123456"}'

# 获取用户信息（需要Token）
curl -X GET http://8.138.190.51/api/auth/me \
  -H "Authorization: Bearer YOUR_TOKEN"

# 上传简历
curl -X POST http://8.138.190.51/api/resume/upload \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@resume.pdf" \
  -F "targetRole=前端开发工程师"

# 一键优化
curl -X POST http://8.138.190.51/api/resume/optimize/1 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"targetRole":"前端开发工程师"}'
```

## 五、错误码说明

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| 用户名已存在 | 注册时用户名被占用 | 更换用户名 |
| 用户名或密码错误 | 登录信息不正确 | 检查用户名和密码 |
| 未登录，请先登录 | Token无效或过期 | 重新登录获取Token |
| 文件格式不支持 | 上传了非PDF/Word文件 | 使用支持的文件格式 |
| 文件解析失败 | 文件内容无法解析 | 检查文件是否损坏 |
| 余额不足 | DeepSeek API余额不足 | 充值API余额 |

## 六、接口流程图

```
用户使用流程:

1. 注册账号
   POST /auth/register
        ↓
2. 登录获取Token
   POST /auth/login
        ↓
3. 上传简历文件
   POST /resume/upload
        ↓
4. 一键优化简历
   POST /resume/optimize/{id}
        ↓
5. 查看优化结果
   GET /resume/{id}
        ↓
6. 继续优化或删除
   POST /ai/optimize 或 DELETE /resume/{id}
```
